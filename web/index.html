🎮 Controles de Validação (Step 0)

O Wasm processa os botões em tempo real, alterando a cor/posição da sprite e a frequência do oscilador de áudio no AudioWorklet:

  • Setas / W A S D : Mover Sprite (D-Pad)
  • X / L : Botão A (Verde / 880 Hz)
  • Z / K : Botão B (Vermelho / Turbo / 587 Hz)
  • C / I : Botão Y (Amarelo / 523 Hz)
  • V / O : Botão X (Roxo / 659 Hz)
  • Gamepad USB/BT : Mapeamento SNES automático
